# 微信云开发配置说明

## 功能说明

本项目已实现基于微信云开发的多人房间功能，所有房间数据存储在云数据库中，支持多人实时同步。

## 配置步骤

### 1. 开通云开发服务

1. 打开微信开发者工具
2. 点击工具栏中的"云开发"按钮
3. 按照提示开通云开发服务
4. 创建云开发环境（可以选择"测试环境"或"正式环境"）

### 2. 创建数据库集合

1. 在云开发控制台中，进入"数据库"页面
2. 点击"创建集合"
3. 集合名称设置为：`rooms`
4. **重要：权限设置**
   - **测试阶段**：建议设置为"所有用户可读写"（方便测试多人功能）
   - **生产环境**：可设置为"所有用户可读，仅创建者可写"（更安全）
   - ⚠️ **如果权限设置不正确，会导致获取房间失败**
   - 设置步骤：创建集合后，点击集合名称进入集合管理页面，点击"权限设置"进行配置

### 3. 配置云开发环境ID

1. 在云开发控制台中，复制你的环境ID（Environment ID）
2. 打开 `miniprogram/app.js` 文件
3. 找到 `wx.cloud.init()` 配置
4. 将 `env` 参数设置为你的环境ID：

```javascript
wx.cloud.init({
  env: 'your-env-id', // 替换为你的云开发环境ID
  traceUser: true,
});
```

### 4. 配置数据库索引（可选，用于优化查询）

1. 在云开发控制台的数据库中，找到 `rooms` 集合
2. 点击"索引管理"
3. 添加索引：
   - 字段：`roomId`
   - 类型：`String`
   - 唯一性：是

## 功能特性

### 1. 房间数据存储
- 所有房间数据存储在云数据库的 `rooms` 集合中
- 每个房间包含：房间ID、玩家列表、回合记录、创建时间等

### 2. 实时数据同步
- 使用云数据库的 `watch` 功能实现实时数据同步
- 当房间数据发生变化时，所有在房间中的玩家会自动收到更新

### 3. API降级策略
- 如果云开发初始化失败或API调用失败，系统会自动降级到本地存储
- 确保在网络问题或配置错误时仍能正常使用（但无法实现多人同步）

## 注意事项

1. **环境ID配置**：必须正确配置云开发环境ID，否则无法连接云数据库
2. **数据库权限**：根据实际需求设置合适的数据库权限
3. **费用**：云开发服务有一定免费额度，超出部分会收费，请注意控制使用量
4. **网络要求**：实时同步功能需要稳定的网络连接
5. **测试建议**：建议先在测试环境中完成配置和测试

## 故障排查

### 问题1：提示"云开发未初始化"

**解决方案**：
- 检查是否已开通云开发服务
- 检查 `app.js` 中的环境ID是否正确配置
- 检查是否在 `app.json` 中添加了 `"cloud": true`

### 问题2：提示"房间不存在"或获取房间失败

**解决方案**：
- **首先检查数据库权限设置**：
  1. 进入云开发控制台 > 数据库
  2. 找到 `rooms` 集合
  3. 点击"权限设置"
  4. 确保权限至少设置为"所有用户可读"（测试阶段建议"所有用户可读写"）
- 检查数据库集合名称是否为 `rooms`（区分大小写）
- 检查房间ID是否正确（6位数字）
- 检查网络连接是否正常
- 检查云开发环境ID是否正确配置
- 查看控制台错误信息，如果是权限错误，需要修改数据库权限

### 问题3：数据无法实时同步

**解决方案**：
- 检查网络连接
- 检查数据库权限设置（需要读取权限）
- 查看控制台是否有错误信息
