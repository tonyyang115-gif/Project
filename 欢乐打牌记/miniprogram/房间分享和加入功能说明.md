# 房间分享和加入功能说明

## 功能概述

实现了房间分享和加入功能，允许创建房间的玩家通过微信的"转发给朋友"功能分享房间，其他玩家可以通过分享链接或手动输入房间ID加入房间。

## 实现的功能

### 1. 房间分享功能
- **位置**：房间页面
- **操作**：点击右上角的"分享"按钮
- **功能**：
  - 使用微信小程序的转发功能（`open-type="share"`）
  - 自动携带房间ID作为分享参数
  - 分享标题包含房间ID信息

### 2. 房间加入功能
- **位置**：首页
- **方式一**：通过分享链接自动加入
  - 收到分享链接的用户打开小程序后，会自动弹出加入房间提示
  - 用户确认后自动加入房间
  
- **方式二**：手动输入房间ID加入
  - 点击首页的"加入房间"按钮
  - 在弹出的对话框中输入6位房间ID
  - 确认后加入房间

### 3. 房间ID显示
- **位置**：房间页面顶部
- **显示内容**：房间ID（6位数字）
- **用途**：方便用户查看房间ID，以便分享或告知其他玩家

## 使用流程

### 创建并分享房间
1. 在首页点击"创建房间"按钮
2. 进入房间页面后，查看房间ID
3. 点击右上角的"分享"按钮
4. 选择"转发给朋友"，选择要分享的好友
5. 好友收到分享链接

### 加入房间
**方式一：通过分享链接**
1. 收到分享链接的用户点击链接
2. 打开小程序后自动弹出加入提示
3. 点击"加入"按钮
4. 自动进入房间页面

**方式二：手动输入房间ID**
1. 在首页点击"加入房间"按钮
2. 在弹出对话框中输入6位房间ID
3. 点击"确定"按钮
4. 进入房间页面

## 技术实现

### 分享功能
- 使用微信小程序的 `button` 组件的 `open-type="share"` 属性
- 在房间页面实现 `onShareAppMessage()` 函数，返回分享配置
- 分享路径携带房间ID参数：`/pages/home/index?roomId=房间ID`

### 加入功能
- 在首页的 `onLoad()` 中检查 URL 参数 `roomId`
- 如果存在分享的房间ID，自动弹出加入提示
- 加入时创建新房间并使用相同的房间ID

### 房间ID
- 房间ID为6位数字，创建时随机生成（100000-999999）
- 房间ID显示在房间页面顶部，方便查看和分享

## 注意事项

### 当前实现的限制

由于房间数据存储在**本地存储**中，存在以下限制：

1. **房间数据无法跨用户同步**
   - 每个用户的房间数据存储在各自的设备上
   - 用户A创建的房间，用户B无法看到用户A的实时数据
   - 用户B加入房间后，会创建一个新房间（使用相同的房间ID），但数据是独立的

2. **无法实现真正的多人房间**
   - 要实现真正的多人实时房间，需要服务器支持
   - 需要将房间数据存储在服务器上，所有用户访问同一个房间数据

### 改进建议

如需实现真正的多人房间功能，建议：

1. **添加服务器支持**
   - 使用云开发或后端服务存储房间数据
   - 实现房间数据的实时同步机制

2. **使用 WebSocket 或轮询**
   - 实现房间数据的实时同步
   - 玩家加入/离开房间时通知所有玩家

3. **房间管理**
   - 实现房间创建、加入、离开的服务器端逻辑
   - 管理房间状态和玩家列表
