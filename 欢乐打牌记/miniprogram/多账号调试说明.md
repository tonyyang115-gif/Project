# 多账号调试模式说明

## 问题描述

在使用微信开发者工具的多账号调试模式时，第二个账号可能会出现以下错误：

1. `cloud init error: Error: access_token missing`
2. `invalid app.json ["cloudbaseRoot"]`
3. `err_code:41001, errMsg: "webapi_getwxaasyncsecinfo:fail access_token missing"`

## 原因分析

这些错误是因为：

1. **access_token 缺失**：在多账号调试模式下，新账号可能还没有完成登录流程，导致云开发初始化时无法获取 access_token。
2. **cloudbaseRoot 配置**：如果项目中不存在 `cloud` 文件夹，`cloudbaseRoot` 配置会导致错误。

## 解决方案

代码已经进行了以下修复：

### 1. 移除 cloudbaseRoot 配置

从 `app.json` 中移除了 `cloudbaseRoot` 配置（因为我们使用的是云数据库，不需要 cloud 文件夹）。

### 2. 延迟初始化云开发

- 云开发初始化不再在 `onLaunch` 时立即执行
- 添加了错误处理和重试机制
- 在真正需要使用云开发时（如调用 API）才进行初始化

### 3. API 层错误处理

- `utils/api.js` 中的 `initCloud` 函数增加了延迟初始化逻辑
- 如果初始化失败，会在使用前自动重试

## 使用建议

### 正常使用

1. **第一个账号**：正常创建房间、加入房间等操作
2. **第二个账号**：
   - 等待几秒钟让云开发初始化完成
   - 如果看到控制台警告信息，可以忽略（会自动重试）
   - 如果仍然无法使用，尝试刷新页面或重新打开小程序

### 调试建议

1. **查看控制台**：注意观察是否有云开发初始化成功的日志
2. **等待登录**：确保第二个账号已经完成登录流程
3. **检查网络**：确保网络连接正常
4. **环境ID检查**：确保 `app.js` 中的云开发环境ID配置正确

## 已知限制

在多账号调试模式下，可能会出现以下情况：

1. 云开发初始化可能会有短暂延迟（1-2秒）
2. 如果账号未完成登录，云开发功能暂时不可用（会显示友好的错误提示）
3. 一旦初始化成功，后续操作都会正常工作

## 故障排查

如果问题持续存在：

1. **检查云开发环境ID**：
   - 打开 `miniprogram/app.js`
   - 确认 `env` 参数是否正确

2. **检查账号登录状态**：
   - 在微信开发者工具中查看账号是否已登录
   - 尝试重新登录

3. **检查数据库权限**：
   - 参考 `问题排查指南.md`
   - 确保数据库权限设置正确

4. **清除缓存**：
   - 在微信开发者工具中清除缓存
   - 重新编译小程序
