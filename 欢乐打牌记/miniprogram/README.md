# 欢乐打牌记 - 微信小程序

## 快速开始

1. 打开微信开发者工具
2. 选择"导入项目"
3. **项目目录选择：`miniprogram` 文件夹**
4. 填写 AppID（测试号可以留空）
5. 点击"导入"

## 重要提示

⚠️ **导入项目时，请选择 `miniprogram` 文件夹作为项目目录，而不是整个项目根目录！**

正确的路径应该是：
```
项目根目录/miniprogram/
```

这样微信开发者工具才能找到 `app.json` 文件。

## 项目结构

```
miniprogram/
├── app.json              # 小程序配置文件（必须）
├── app.ts                # 小程序入口
├── app.wxss              # 全局样式
├── pages/                # 页面目录
│   ├── home/            # 首页
│   ├── room/            # 房间页面
│   ├── history/         # 历史战绩
│   └── profile/         # 个人中心
├── components/          # 组件
└── utils/               # 工具函数
```

## 功能说明

- ✅ 创建房间
- ✅ 快捷记分
- ✅ 自由输入记分
- ✅ 积分划转
- ✅ 最终结算
- ✅ 历史记录

## 注意事项

如果导入时仍然提示找不到 `app.json`，请检查：
1. 是否选择了 `miniprogram` 文件夹作为项目目录
2. `miniprogram` 文件夹下是否存在 `app.json` 文件
3. 文件路径中是否包含中文字符（如有，请移动到英文路径）
