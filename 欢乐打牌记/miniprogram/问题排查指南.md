# 问题排查指南

## 常见问题及解决方案

### 1. 获取房间失败错误

**错误信息**：
```
api.js:92 获取房间失败 Error
```

**可能的原因和解决方案**：

#### 原因1：数据库权限不足
**解决方案**：
1. 打开微信开发者工具
2. 点击"云开发"按钮
3. 进入"数据库"页面
4. 找到 `rooms` 集合
5. 点击集合名称进入集合管理
6. 点击"权限设置"
7. **测试阶段**：选择"所有用户可读写"
8. **生产环境**：选择"所有用户可读，仅创建者可写"
9. 保存设置

#### 原因2：云开发环境ID未配置或配置错误
**解决方案**：
1. 打开 `miniprogram/app.js`
2. 检查 `wx.cloud.init()` 中的 `env` 参数
3. 确保环境ID与云开发控制台中的环境ID一致
4. 环境ID在云开发控制台的"设置" > "环境设置"中查看

#### 原因3：数据库集合不存在
**解决方案**：
1. 在云开发控制台创建 `rooms` 集合
2. 确保集合名称完全一致（区分大小写）

#### 原因4：房间ID不存在
**解决方案**：
1. 确保输入的房间ID是正确的6位数字
2. 房间ID由房主创建时生成
3. 确保房主已成功创建房间并保存到数据库

### 2. 进入房间后看不到数据

**可能的原因**：
- 房间数据获取失败
- 数据结构不完整

**解决方案**：
1. 检查控制台错误信息
2. 按照"获取房间失败"的解决方案检查数据库权限
3. 确认房间ID是否正确
4. 尝试刷新页面或重新加入房间

### 3. 房间号无显示

**解决方案**：
- 代码已修复，房间号现在会显示
- 如果仍然不显示，检查 `room.roomId` 是否在数据库中正确保存

### 4. 点击积分明细无法显示

**可能的原因**：
- 房间数据中的 `rounds` 字段为空或格式不正确
- 玩家数据不完整

**解决方案**：
1. 检查房间数据是否包含 `rounds` 数组
2. 确保每个回合数据格式正确
3. 检查玩家数据是否包含 `name` 和 `avatarUrl`

### 5. 看不到房主和其他玩家

**可能的原因**：
- `players` 数组为空
- 玩家数据格式不正确

**解决方案**：
1. 检查数据库中的 `players` 字段是否包含数据
2. 确保每个玩家对象包含必需的字段：`id`, `name`, `avatarUrl`, `totalScore`
3. 如果玩家数据为空，检查加入房间的逻辑是否成功

## 调试步骤

1. **查看控制台错误信息**
   - 打开微信开发者工具的控制台
   - 查看详细的错误信息

2. **检查数据库数据**
   - 进入云开发控制台 > 数据库
   - 查看 `rooms` 集合中的数据
   - 确认数据格式是否正确

3. **检查网络连接**
   - 确保网络连接正常
   - 检查云开发服务是否正常

4. **检查权限设置**
   - 这是最常见的问题
   - 确保数据库权限设置正确

## 测试建议

1. **创建房间测试**
   - 使用一个微信账号创建房间
   - 记录房间ID
   - 检查数据库中是否创建了房间数据

2. **加入房间测试**
   - 使用另一个微信账号（或清除缓存后）
   - 输入房间ID尝试加入
   - 检查是否成功加入

3. **数据同步测试**
   - 在两个设备上同时打开同一房间
   - 在一个设备上进行操作（如添加分数）
   - 检查另一个设备是否自动更新
